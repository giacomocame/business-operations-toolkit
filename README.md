# 🚀 Business Operations & Ops Excellence Toolkit

Welcome to my professional portfolio. This repository contains a suite of Python-based automation tools and standalone Single Page Application (SPA) dashboards designed for Manufacturing and Business Operations.

The goal of these tools is to bridge the gap between raw data and executive decision-making, replacing heavy, legacy Excel workflows with fast, interactive, and serverless web tools.

## 🧰 The Toolkit

| Project | Description | Live Demo / Link |
| :--- | :--- | :--- |
| **[01. Plant Efficiency Dashboard](01_plant_efficiency)** | Bottom-up daily tracking of standard vs actual variances at the machine/cost-center level. | [View Live App](https://giacomocame.github.io/business-operations-toolkit/01_plant_efficiency/) |
| **[02. Supply Chain Command Deck](02_supply_chain_deck)** | Top-down executive SVG gauge dashboard aggregating multiple manufacturing plants. | [View Live App](https://giacomocame.github.io/business-operations-toolkit/02_supply_chain_deck/) |
| **[03. Extra Consumptions Tracker](03_extra_consumptions)** | Interactive tracking of Scrap, Extrapicking, and negative variances with automated root-cause extraction. | [View Live App](https://giacomocame.github.io/business-operations-toolkit/03_extra_consumptions/) |
| **[04. Indirect Materials Analytics](04_indirect_materials_analytics)** | In-browser BI tool with sub-millisecond search engine for tracking indirect manufacturing costs. | [View Live App](https://giacomocame.github.io/business-operations-toolkit/04_indirect_materials_analytics/) |
| **[05. Desktop Command Deck](05_desktop_command_deck)** | Native Python CustomTkinter GUI featuring multithreading and thread-safe console logging. | [View Desktop UI](https://github.com/giacomocame/business-operations-toolkit/tree/main/05_desktop_command_deck) |

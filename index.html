Business Operations & Ops Excellence Toolkit

The goal of these tools is to bridge the gap between raw data and executive decision-making. I focus on replacing heavy, legacy Excel workflows with fast, interactive, and serverless web applications. All tools below are built entirely with Python (Pandas/Plotly) and Vanilla JS, demonstrating automated ETL pipelines and offline hydration.

01. Plant Efficiency Dashboard

🏭

Bottom-up daily tracking of standard vs actual variances at the machine and cost-center level. Replaces local macro-heavy Excel files.

SERVERLESS SPA PANDAS

02. Supply Chain Command Deck

🌐

Top-down executive SVG gauge dashboard aggregating multiple manufacturing plants to extract global supply chain efficiency metrics.

CUSTOM DATA VIZ SVG GRAPHICS

03. Extra Consumptions Tracker

📉

Interactive tracking of Scrap, Extrapicking, and negative variances with automated root-cause extraction and expandable cascade tables.

COST CONTROLLING SERVERLESS SPA

04. Indirect Materials Analytics

📦

In-browser BI tool with sub-millisecond client-side search engine for tracking indirect manufacturing costs and specific operator actions.

CLIENT-SIDE SEARCH PANDAS

💻

Native Python CustomTkinter GUI featuring multithreading and thread-safe console logging for the internal Operations team.
